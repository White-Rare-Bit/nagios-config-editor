Object Explorer

The Object Explorer is the main interface for browsing and editing your Nagios configuration. It uses a three-pane layout: a tree of objects on the left, an attribute editor in the center, and a workspace panel with file management, analysis, and suggestions on the right.

Left Pane: Object Tree

The left pane shows every object in your configuration organized as a tree. You can switch between two views using the tabs at the top of the pane:

  • By File — objects grouped under their source .cfg file. Expand a file to see the objects defined in it. Each file header shows the object count.
  • By Type — objects grouped by Nagios type (host, service, command, contact, etc.). Useful when you want to see all objects of one kind regardless of which file they live in.

Click a folder header to expand or collapse it. The tree remembers which folders you have open across page refreshes.

Tree Search

The search box at the top of the tree filters objects by name, type, or attribute values. Type a search term and the tree instantly narrows to show only matching objects. Clear the search to restore the full tree.

Filter Checkboxes

Below the search box, two checkboxes let you focus on specific subsets:

  • Orphans only — show only objects not referenced by any other object.
  • Issues only — show only objects flagged with validation issues (missing references, duplicates, unused templates, etc.).

Visual Indicators in the Tree

Objects in the tree show several visual cues:

  • A type badge next to each object name (e.g. "host", "service template").
  • A staged move arrow (→) on objects that have been staged to move to another file.
  • A green plus badge (+) on newly created objects that have not yet been committed.
  • A deletion strikethrough with an Undo button on objects staged for deletion.
  • Issue badges with icons indicating the type of problem (missing reference, duplicate, unused, etc.).
  • A drag handle on the left side for drag-and-drop moves between files.

Center Pane: Attribute Editor

When you select an object in the tree, the center pane shows its full attribute editor. This is where you view and modify every directive on the object. See Editing Objects for a detailed walkthrough of the editor.

When no object is selected, the center pane shows an empty state prompt. When multiple objects are selected, it shows a count and points you to the Actions menu for bulk operations.

Tab Bar

The center pane has a tab bar at the top. Each object you open appears as a tab, similar to a code editor. Click tabs to switch between objects. Middle-click or click the close button on a tab to close it. Tabs persist within your browser session.

Right Pane: Workspace

The right pane is a tabbed workspace with several views:

  • Files — a file/folder tree of your config directory. Right-click for context menus to create, rename, move, or delete files and folders. This is also the drop target when dragging objects to move them.
  • Suggestions — automated analysis of your configuration. Shows template consolidation opportunities, hostgroup suggestions, and other cleanup recommendations.
  • Errors — grouped validation errors from cross-referencing your objects. Shows missing templates, undefined commands, broken references, and similar issues.
  • Validation — run nagios -v against your configuration and view the output inline.

Selecting Objects

Click an object in the tree to select it and open it in the editor. You can also multi-select for bulk operations:

  • Single click — selects one object and clears the previous selection.
  • Ctrl+click (or Cmd+click on Mac) — toggles an individual object in the selection without affecting others.
  • Shift+click — selects a range from the last-selected object to the clicked one.

Selection Helpers

The Actions menu in the toolbar provides selection shortcuts:

  • Select All Visible — selects every object currently visible in the tree (respects search filters).
  • Select by Type — opens a dialog to pick an object type, then selects all objects of that type.
  • Select by Pattern — opens a dialog for a regex pattern, then selects all objects whose name matches.

Drag and Drop

You can move objects between files by dragging them from the left-pane tree and dropping them on a file in the right-pane workspace. When you start dragging, the app automatically switches to the Files tab in the right pane and highlights valid drop targets. A badge shows the count of objects being dragged.

Drag-and-drop moves are staged — they appear in the commit dialog and are not written to disk until you click Apply.

Context Menus

Right-click an object in the tree to open a context menu with these actions:

  • Rename — change the object's name field.
  • Clone — create a copy of the object with a new name.
  • Move to file — move selected objects to a different config file.
  • Add to group — add selected hosts, services, or contacts to a group.
  • View in Graph — open the object in the dependency graph view.
  • Delete — stage selected objects for deletion.

When multiple objects are selected, the context menu actions apply to the entire selection (bulk clone, bulk move, bulk delete, etc.).

Quick Preview

Press Space while hovering over an object in the tree to open a quick preview modal. This shows the full Nagios define { ... } block as it would appear in the config file, including any staged edits. Press Escape to close the preview.

Keyboard Shortcuts

Shortcut Action
Ctrl+Z / Cmd+Z Undo the last staging operation
? Open the keyboard shortcuts help dialog
Space Quick preview of the hovered or selected object
Escape Close any open dialog, preview, or context menu
On macOS, Cmd is used in place of Ctrl for all modifier shortcuts. The keyboard shortcuts help dialog (press ?) automatically shows the correct modifier for your platform.
