Quick Start

This guide walks you through the basic workflow: loading your configuration, making changes, reviewing them, and applying them to disk.

1. Load Configuration

When the app starts, it automatically reads all .cfg files from your configured Nagios directory. Navigate to the Object Explorer page to begin browsing your configuration.

2. Browse Objects

The Object Explorer uses a three-pane layout:

  • Left pane — a tree of your config files and folders. Click a file to view its contents.
  • Center pane — lists all objects defined in the selected file. Click an object to edit it.
  • Right pane — the attribute editor for the selected object. Each attribute is shown as an editable field.

3. Make Changes

Edit any attribute in the right pane — your changes are staged immediately. A staging indicator in the navbar shows how many changes are pending.

You can also:

  • Add attributes — use the add attribute control at the bottom of the editor
  • Delete attributes — clear an attribute's value to remove it
  • Move objects — drag objects between files in the explorer
  • Create new objects — add new Nagios object definitions
  • Create files and folders — organize your configuration structure

4. Review Changes

Click the Commit button in the navbar to open the commit dialog. This shows a diff of every staged change — edits, moves, creations, and deletions — so you can review exactly what will be written to disk.

5. Apply

Click Apply in the commit dialog to write all staged changes atomically to disk. A backup is created automatically before any files are modified.

If Git is configured for your Nagios config directory, you can enter a commit message and commit the changes directly from the same dialog.

6. Validate

After applying changes, navigate to the Validate page and run nagios -v to verify your configuration is valid. Fix any errors and repeat the cycle.

Until you click Apply, no changes are written to disk. You can undo individual changes or clear all staging at any time.
