Dependency Graph

The Graph View page (accessible from the navbar as "Graph View") visualizes relationships between Nagios objects as an interactive node-and-edge diagram. It uses the Cytoscape.js library to render a zoomable, pannable graph where each node represents a Nagios object and each edge represents a reference between them.

Adding Nodes

The graph starts empty. Use the search box in the left sidebar to find an object by name, then click it (or use the arrow keys and Enter) to add it to the graph. Exact and prefix matches are listed first; the type selector under the search box limits results to one object type. The first object you add becomes the focus node.

Quick Views

Once the graph has a focus node, quick view buttons appear in the sidebar. Each one rebuilds the graph around the focus node to answer one question, collecting only the object types and showing only the connections that question needs, with a layout to suit. The available views depend on the focus node's type:

View Available For Shows
Inheritance All types The templates the object inherits from, top to bottom. For a template, also the objects that inherit from it.
Network Hosts Host parent/child topology and bound services.
Services Hosts All services monitoring this host.
Notifications Hosts, services Notification routing to contacts and contact groups.
Members Groups All members of the selected group.
Notified By Contacts Objects that send notifications to this contact.
Used By Commands, timeperiods All objects that reference this command or timeperiod.
Monitoring Hosts, services Check commands and time periods assigned to this object.
Escalations Hosts, services, their groups, escalations Escalation rules and their contacts.
Dependencies Hosts, services, their groups, dependencies Dependency rules (master/dependent relationships).
Full Graph All types Everything Nagios applies to the object: its templates, services (directly and through hostgroups), commands, contacts, time periods, groups, and the dependency and escalation rules that name it.

Filtering

The Custom Filters section in the sidebar offers two ways to control what the graph displays:

  • Object type checkboxes — show or hide nodes by type (host, service, contact, command, etc.). Unchecking a type hides those nodes and their edges.
  • Nodes list — lists every object in the graph. The count reads "12 of 26" when filters hide some of them, and hidden entries are dimmed and marked hidden (hover for the reason).
  • Edge category checkboxes — show or hide edges by relationship category:
    • Dependencies — host parents, host/service dependencies
    • Templates — inheritance via use
    • Groups — group membership
    • Contacts — notification routing
    • Commands — check commands, event handlers
    • Schedules — time periods, escalation periods
    A quick view shows only the connections it follows; changing a category box switches to filtering by category.

Layout Options

The layout dropdown controls how nodes are arranged:

  • Clustered — the focus node in the middle with each object type in its own cluster around it (contacts, services, commands and time periods in rings orbiting the contact groups); edges bend toward the cluster they point into. Without a focus node, a force-directed layout. Used by Full Graph.
  • Hierarchical (Top-Bottom) — ranked by edge direction: an object sits above what it refers to, except that templates sit above the objects that use them and parent hosts above their children. Good for inheritance chains and network topology.
  • Hierarchical (Left-Right) — the same ranking, left to right. Good for notification routing and escalation paths.

Quick views automatically select the layout that best fits the relationship type.

Graph Interaction

  • Hover — shows a node's details (type, full host list, whether it is defined) and highlights its connections, fading everything else. Selecting a single node keeps it highlighted. Hovering an edge names its field.
  • Pan — click and drag the canvas background.
  • Zoom — scroll wheel or pinch gesture.
  • Select — click a node. Shift+click for multi-select. Shift+drag for box selection.
  • Delete — press Delete or Backspace to remove selected nodes (not while a sidebar control has focus).
  • Fit to View — button in the sidebar to auto-zoom so all nodes are visible.
  • Toggle Edge Labels — show or hide relationship labels on edges.

Filtering, toggling labels and removing nodes keep your zoom, pan and any nodes you dragged; the layout runs again only when you change it, change the focus node, or new objects are added.

Context Menu

Right-click any node to access:

  • Expand connections — add what Nagios applies to the object (as in Full Graph) to the graph.
  • Show only connections — isolate this node and its immediate connections, removing everything else.
  • Center on node — pan and zoom to this node.
  • Set as focus node — make this node the one quick views start from and the clustered layout centres on.
  • Remove from graph — remove just this node.
  • Remove disconnected — remove all nodes that have no edges.
  • Open in Explorer — navigate to this object in the Object Explorer. Clicking an entry in the nodes list does the same.

Node Appearance

Each object type has a distinct color and icon. Templates are drawn with a dashed border, objects that are referenced but not defined in your configuration with a red X, and objects added through a + (additive) reference with a green "+" badge. A service's label names its hosts or hostgroups, shortened to a count ("HTTP / 9 hosts") when the list is long; hover for the full list. The Legend in the top-right corner (closed by default) explains the object types, markers and connection colors in the current graph.

State Persistence

The page address always describes the current graph, so you can bookmark it, reload it, or send it to someone. A quick view is recorded as its focus node and view (?node=host:web-server&view=services); a graph you changed by hand also lists its nodes, filters and layout. Opening the Graph View from the navbar restores the last graph from this browser tab. Use the Clear button in the nodes list to start fresh.

/dependencies?node=type:name opens the graph on that object's Full Graph; add &view= with a quick view name (inheritance, services, notifications, ...) to open another view.
