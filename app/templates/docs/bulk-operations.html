Bulk Operations

Nagios Bulk Editor is designed for making changes across many objects at once. You can multi-select objects in the tree and apply operations to the entire selection, or use the Edit Attributes dialog to run find & replace across your full configuration.

Multi-Select

Select multiple objects in the tree using standard modifier keys:

  • Ctrl+click (Cmd+click on Mac) — toggle individual objects in the selection.
  • Shift+click — select a contiguous range from the last-selected object to the clicked one.

When multiple objects are selected, the center pane shows a count of the selection and directs you to the Actions menu for bulk operations.

Selection Shortcuts

The Actions menu provides quick selection helpers:

  • Select All Visible — selects every object currently shown in the tree (respects any active search filter or checkbox).
  • Select by Type — opens a dialog listing all object types with counts. Click a type to select all objects of that type.
  • Select by Pattern — opens a dialog for a regex pattern. All objects whose display name matches the pattern are selected.

Bulk Actions via Context Menu

Right-click with multiple objects selected to see bulk actions:

  • Move to File — opens a dialog with a file dropdown. Select the target file (or create a new one) to stage all selected objects for a move.
  • Clone — opens a dialog to enter a name suffix (default: -copy). Each selected object is cloned with the suffix appended to its name. The clones are staged as new objects in the same file as their source.
  • Add to Group — for hosts, services, or contacts. Opens a dialog with group search. The selected objects get the group added to their group membership attribute (e.g. hostgroups for hosts, servicegroups for services, contactgroups for contacts).
  • Delete — stages all selected objects for deletion. If any of the selected objects are referenced by other objects, a dependency warning dialog shows exactly which objects will be affected before you confirm.

Edit Attributes Dialog

The Edit Attributes dialog (available from the Actions menu) is the most powerful bulk editing tool. It supports three modes:

Find & Replace

Search for a text string within attribute values and replace it with a new string. You can scope the operation to a specific attribute or leave the attribute field empty to search across all attributes on every selected object.

  • Attribute — optional. An autocomplete dropdown shows all attributes present on the selected objects. Leave empty to search all fields.
  • Find text — the exact text to search for within attribute values.
  • Replace with — the replacement text. Can be empty to delete the found text.

If no objects are selected, find & replace operates on every object in the configuration.

Set Value

Set a specific attribute to a given value on all selected objects. Useful for standardizing a directive across many objects at once — for example, setting check_interval to 5 on every selected service.

Reference field values are validated against existing objects. If you try to set check_command to a command that does not exist, the operation is rejected with an error message.

Remove Attribute

Remove a specific attribute from all selected objects. The attribute is deleted from each object that has it, and objects that do not have the attribute are skipped.

Bulk Rename

The Bulk Rename option in the Actions menu opens a find-and-replace dialog that operates specifically on object names. Enter the text to find and the replacement text — each selected object whose name contains the search text will have that portion replaced.

For example, selecting all hosts matching web- and replacing with app- renames web-server01 to app-server01, web-server02 to app-server02, and so on.

Drag-and-Drop Bulk Move

When you have multiple objects selected, dragging any one of them starts a bulk drag of the entire selection. A badge on the drag cursor shows the count. Drop onto a file in the right pane's Files tab to stage a move for all selected objects.

All bulk operations are staged, not applied immediately. After performing a bulk operation, review the changes in the commit dialog before applying them to disk. You can undo individual changes or clear all staging if the result is not what you intended.

Dependency Warnings

When you delete objects that are referenced by other objects, the app shows a dependency warning dialog before proceeding. The dialog categorizes the impact:

  • Orphaned services — services that will lose their host_name or hostgroup_name reference, which means Nagios will fail to load them.
  • Broken references — other objects that reference the deleted object by name in fields like use, check_command, contacts, etc.

You can still proceed with the deletion, but the dialog makes sure you understand the consequences.
