Search & Filtering

Nagios configurations can contain hundreds or thousands of objects. Nagios Bulk Editor provides several search and filtering tools to help you find what you need quickly. All searches run entirely in the browser — results appear instantly as you type.

Object Tree Search

At the top of the left pane in the Object Explorer, a search box labeled "Search objects..." filters the object tree in real time. The search matches against:

  • Object names — the display name of each object (e.g., a host's host_name, a service's service_description).
  • Object types — type "host" to see only hosts, "service" for services, etc.
  • Attribute keys and values — any attribute on any object is searchable. For example, searching for "192.168" will find hosts whose address attribute contains that subnet.
  • File names — in the "By File" view, matching file names are included in the results.

The tree collapses to show only matching items and their parent containers (files or type groups). Clear the search box to restore the full tree.

Filter Checkboxes

Below the search box, two filter checkboxes let you narrow the tree further:

Filter Description
Orphans Show only objects that are not referenced by any other object. These are potential cleanup candidates — a host template that no host uses, or a command that no service references.
Issues Show only objects with configuration errors, such as missing required fields or references to non-existent objects. Issue counts appear as badges on tree nodes.

Filters stack: you can combine the search box with one or both checkboxes. For example, type "service" in the search box and check "Issues" to find all services with configuration problems.

Tree View Modes

The left pane offers two view modes that affect how the tree is organized:

  • By File — objects grouped under their source .cfg file. Useful for understanding file organization.
  • By Type — objects grouped by their Nagios type (hosts, services, commands, etc.). Useful when you want to see all objects of one kind regardless of which file they live in.

The search and filter options work identically in both view modes.

Documentation Search

On the Docs page, a separate search box at the top of the sidebar filters the documentation tree. This search works across both sections of the tree:

  • App Docs — matches page titles and section names in the user guide and developer guide.
  • Nagios Reference — matches Nagios object type names (e.g., "host", "servicegroup", "timeperiod").

When you type a search term, both tree sections expand automatically to show matching items. Clear the search box or press Escape to reset.

Directive Search

Inside any Nagios Reference page, a "Filter directives..." input appears above the directive table. This filters the attribute list for that specific object type, making it easy to find a particular directive in types that have many attributes.

Tips

  • Searches are case-insensitive. Typing "WEB" finds objects named "web-server" or "WebApp".
  • In the Object Explorer, the search result count is not displayed explicitly, but the tree visually collapses to show only matches, making it clear what was found.
  • Combine the Orphans filter with a type search (e.g., "command" + Orphans) to find unused commands for cleanup.
