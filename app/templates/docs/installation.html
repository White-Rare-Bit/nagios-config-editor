Installation

Requirements

  • Python 3.8+
  • Flask 2.0+ (installed automatically via requirements.txt)
  • Access to your Nagios .cfg configuration files
  • Git (optional — needed only for version control features)

Install Dependencies

Clone or download the application, then install the Python dependencies: 

pip install -r requirements.txt

This installs Flask and any other required packages. There are no external databases or additional services to set up.

Configuration

Application settings are stored in config/settings.json. The key settings are:

Setting Description Default
nagios_config_path Directory containing your Nagios .cfg files ./sample-config
nagios_bin Path to the Nagios binary (for validation) /usr/local/nagios/bin/nagios
nagios_cfg Path to the main nagios.cfg file ./sample-config/nagios.cfg
backup_path Directory where backups are stored null (auto-created in config dir)

You can configure these settings in three ways, listed in order of precedence:

  1. Environment variables — override all other settings
  2. Settings page — edit config/settings.json from within the app
  3. Config file — edit config/settings.json directly

Running the App

Start the development server:

python3 app.py

The app runs on port 8080 by default. Open http://localhost:8080 in your browser to access it.

For production use, run the app behind a WSGI server such as Gunicorn or uWSGI instead of the built-in Flask development server. The application uses multiprocessing.Lock for thread safety, so it is compatible with multi-process WSGI deployments.
