Keyboard Shortcuts

Nagios Bulk Editor supports keyboard shortcuts for common operations. Press ? at any time (when not typing in a text field) to open the shortcuts help overlay inside the application.

On macOS, Ctrl is replaced by Cmd for modifier shortcuts. The help overlay detects your platform and shows the correct modifier key.

General

These shortcuts work on every page of the application.

Shortcut Action
Ctrl + Z Undo last action. Pops the most recent operation from the undo stack (only when not typing in a text field and no dialog is open).
Escape Close the current dialog, overlay, or preview. Also clears the object selection in the explorer if no object is being edited.
? Show the keyboard shortcuts help overlay.

Object Explorer

These shortcuts are specific to the Object Explorer page.

Shortcut Action
Space Quick preview the selected object as raw Nagios config syntax. Shows a read-only preview of the define block.

Selection

These mouse-based shortcuts control how objects are selected in the tree.

Shortcut Action
Ctrl + Click Toggle an individual item in the selection. The clicked item is added to or removed from the current selection without affecting other selected items.
Shift + Click Select a range of items. All items between the last clicked item and the current click target are selected.
Right-click Open the context menu for the clicked object. Provides actions like Rename, Clone, Delete, Move to file, Add to group, and View in Graph.

Autocomplete

When editing attribute values in the center pane, certain fields offer autocomplete suggestions (for example, host_name suggests existing hosts, check_command suggests known commands).

Shortcut Action
↓ ↑ Navigate through the suggestions list. The highlighted suggestion moves up or down.
Enter Accept the currently highlighted suggestion and insert it into the field.
Escape Close the suggestions dropdown without accepting any value.

Drag & Drop

Drag and drop is used to move objects between files and to reorganize the workspace tree.

Action Description
Drag object from tree Move an object (or the entire selection) to a different file. Drag from the left pane tree and drop onto a file in the workspace tab.
Drag file or folder Move a file or folder to a different parent folder in the workspace tree.
Hover over folder (800 ms) While dragging, hovering over a collapsed folder for 800 milliseconds will automatically expand it, allowing you to drop into nested folders.

Keyboard shortcuts are disabled when the cursor is inside a text input, textarea, or content-editable element to avoid interfering with normal typing.
