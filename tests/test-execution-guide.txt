This guide documents WHERE to click and WHAT to click for each test step.

================================================================================
UI LAYOUT REFERENCE
================================================================================

LEFT PANEL (Objects Tree):
- File headers: "HOSTS.CFG", "COMMANDS.CFG", etc. (click to expand/collapse)
- Objects inside files: Listed below each file header
- Object row structure:
  [warning icon if any] [object name TEXT] [TYPE badge]

  Example: [!] web-prod-01 [HOST]
           ^^^^^^^^^^^^^ <- RIGHT-CLICK HERE for context menu

CENTER PANEL (Object Editor):
- Shows selected object's attributes
- Editable fields for each attribute
- "+ Add attribute" button at bottom

RIGHT PANEL (Workspace/Files):
- Files tab: Shows folder/file structure
- Suggestions tab: Shows issues/recommendations
- Validation tab: Shows config validation

TOP BAR:
- Undo button (with count badge)
- Commit button (with count badge) - RED when changes pending
- Settings, Reload buttons

================================================================================
PHASE 1: BASIC OBJECT OPERATIONS
================================================================================

STEP 1: CREATE A NEW HOST
-------------------------
WHERE TO CLICK:
1. LEFT PANEL: Find "HOSTS.CFG" file header
2. Click the [+] button next to "HOSTS.CFG" label
   - This opens a new object form in CENTER PANEL
3. CENTER PANEL: Fill in the fields:
   - host_name: type "test-staging-host"
   - alias: type "Test Host for Staging"
   - address: type "192.168.1.100"
4. Object automatically saves as you type

VERIFICATION:
- LEFT PANEL: New object appears with green "+" badge
- TOP BAR: Commit button count increases
- TOP BAR: Undo button count increases


STEP 2: EDIT HOST ATTRIBUTES
----------------------------
WHERE TO CLICK:
1. LEFT PANEL: Click on the object NAME text (e.g., "test-staging-host")
   - This selects the object and shows it in CENTER PANEL
2. CENTER PANEL: Click in the "alias" text field
   - Change value to "Test Host - Modified"
3. CENTER PANEL: Click "+ Add attribute" button (bottom of editor)
4. DIALOG appears:
   - Click on "max_check_attempts" in the suggestions list
   - Type "5" in the Value field
   - Click "Confirm" button

VERIFICATION:
- Changes save automatically
- For staged creations: object keeps "+" badge (edits modify the creation)
- For committed objects: object gets blue "~" edit badge


STEP 3: CLONE/DUPLICATE AN OBJECT
---------------------------------
WHERE TO CLICK:
1. LEFT PANEL: Find the object to clone
2. RIGHT-CLICK on the object NAME text (NOT the container row, NOT the type badge)

   CORRECT:   Right-click on "web-prod-01" text
   WRONG:     Right-click on [HOST] badge
   WRONG:     Right-click on warning icon

3. CONTEXT MENU appears with options:
   - Rename...
   - Clone...        <- CLICK THIS
   - Move to file...
   - Add to group...
   - View in Graph
   - Delete

4. CLONE DIALOG appears:
   - "New name" field shows default: "objectname-copy"
   - Edit the name to your desired clone name
   - Click "Confirm" button

VERIFICATION:
- New cloned object appears in tree with green "+" badge
- Commit count increases by 1

NOTE: Clone may not work on staged (uncommitted) objects. Use committed objects.


STEP 4: RE-ORDER OBJECT WITHIN SAME FILE
----------------------------------------
WHERE TO CLICK:
1. This requires DRAG-AND-DROP in the RIGHT PANEL (Workspace)
2. RIGHT PANEL: Click "Files" tab
3. Expand the file containing the objects
4. DRAG an object UP or DOWN within the same file

VERIFICATION:
- Object order changes
- Orange move indicator appears

NOTE: This is difficult to automate with accessibility-tree testing.


STEP 5: MOVE HOST TO NEW FILE
-----------------------------
WHERE TO CLICK:
1. LEFT PANEL: RIGHT-CLICK on the object NAME text to move
2. CONTEXT MENU: Click "Move to file..."
3. MOVE DIALOG appears:
   - "Target file" dropdown: Click to see file list
   - Select destination file OR
   - Click "+ Create new file..." and enter filename
   - Click "Confirm" button

VERIFICATION:
- Object shows orange arrow badge (move indicator)
- Commit count increases


================================================================================
PHASE 2: FOLDER OPERATIONS
================================================================================

STEP 6: CREATE A NEW FOLDER
---------------------------
WHERE TO CLICK:
1. RIGHT PANEL: Click "Files" tab
2. Click "Create new folder" button (usually near top of Files panel)
3. DIALOG appears:
   - Enter folder name: "test-staging-folder"
   - Click "Confirm"

VERIFICATION:
- New folder appears in file tree with "NEW" badge
- Commit count increases


STEP 7: MOVE FILE TO FOLDER
---------------------------
WHERE TO CLICK:
1. RIGHT PANEL: DRAG a .cfg file onto the target folder
   OR
2. RIGHT-CLICK on file > "Move to folder..." > select target

VERIFICATION:
- File appears under the folder
- Staged file move indicator visible


STEP 8: CREATE A SUB-FOLDER
---------------------------
CURRENT BEHAVIOR (BUG):
- The "Create new folder" button always creates at ROOT level
- Selecting a parent folder first does NOT create inside it

WORKAROUND:
- Use drag-and-drop to move folders after creation

================================================================================
PHASE 5: DELETION OPERATIONS
================================================================================

STEP 13: STAGE OBJECT DELETION
------------------------------
WHERE TO CLICK:
1. LEFT PANEL: Click on object NAME to select it
2. Either:
   a) Press DELETE key on keyboard
   OR
   b) RIGHT-CLICK on object NAME > Click "Delete" (red text)
3. CONFIRMATION DIALOG: Click "Confirm"

VERIFICATION:
- Object shows red "x" badge (deletion staged)
- Object remains visible but marked for deletion
- Commit count increases

| Move to file...  |

RIGHT-CLICK on FOLDER shows different menu (folder operations)

================================================================================
KEYBOARD SHORTCUTS
================================================================================

Ctrl+Z (Cmd+Z on Mac) = Undo last operation
Delete                = Stage deletion of selected object
Escape                = Close any open dialog
Arrow Up/Down         = Navigate objects in tree
Space                 = Preview selected object

================================================================================
BADGE REFERENCE
================================================================================

GREEN "+"     = Staged creation (new object)
BLUE "~"      = Staged edit (modified object)
ORANGE arrow  = Staged move (object being moved)
RED "x"       = Staged deletion (object to be deleted)
"NEW"         = Staged file/folder creation
"PENDING"     = Object not yet committed

================================================================================
COMMON ISSUES
================================================================================

1. CLONE DIALOG DOESN'T OPEN:
   - You're clicking on the wrong element
   - Must right-click on the OBJECT NAME text specifically
   - NOT on: container row, type badge, warning icon, file header

2. CONTEXT MENU SHOWS WRONG OPTIONS:
   - You clicked on a file header instead of an object
   - File headers show file operations, objects show object operations

3. DIALOG STUCK OPEN:
   - Press Escape multiple times
   - Click Cancel if visible

4. SUBFOLDER CREATED AT ROOT:
   - Known bug: "Create new folder" ignores parent selection
   - Use drag-and-drop to reorganize after creation
