================================================================================
PHASE 1: BASIC OBJECT OPERATIONS
================================================================================

STEP 1: CREATE A NEW HOST
-------------------------
Action:
  - Navigate to Explorer view
  - Right-click on an existing .cfg file (e.g., hosts.cfg)
  - Select "Create Object" > "host"
  - Enter attributes:
      host_name: test-staging-host
      alias: Test Host for Staging
      address: 192.168.1.100
      use: generic-host (if template exists)
  - Click "Create"

Expected:
  - Green "+" badge appears on the new object in tree
  - Object appears in staging as "creation"
  - Commit button shows badge count increased by 1
  - Undo stack count is 1


STEP 2: EDIT THE HOST ATTRIBUTES
--------------------------------
Action:
  - Select the newly created host "test-staging-host"
  - In the center pane editor, modify attributes:
      alias: "Test Host - Modified"
      address: 192.168.1.200
      Add new attribute: max_check_attempts = 5
  - Click "Stage Changes" or press Enter

Expected:
  - Blue "~" (edit) badge appears on the object
  - Commit button badge count increased
  - Undo stack count is 2


STEP 3: CLONE/DUPLICATE AN OBJECT
---------------------------------
Action:
  - Right-click on "test-staging-host"
  - Select "Clone" or "Duplicate"
  - In the clone dialog:
      New name: test-staging-host-clone
      Keep other attributes the same
  - Click "Clone"

Expected:
  - New object "test-staging-host-clone" appears in tree
  - Green "+" badge on the cloned object
  - Commit button badge count increased
  - Undo stack count increased


STEP 4: RE-ORDER OBJECT WITHIN SAME FILE
----------------------------------------
Action:
  - In the same .cfg file, identify two adjacent objects
  - Drag an object UP or DOWN within the same file
  - OR right-click > "Move Up" / "Move Down" if available
  - Move "test-staging-host" below "test-staging-host-clone"

Expected:
  - Object order changes in the tree view
  - Orange move indicator appears (same-file reorder)
  - Commit button badge count increased
  - Undo stack count increased
  - Note: Same-file moves use different code path than cross-file moves


STEP 5: MOVE HOST TO A NEW FILE
-------------------------------
Action:
  - Create a new file first:
      - Right-click in target pane (file tree)
      - Select "New File"
      - Name: "test-staging-objects.cfg"
  - Drag "test-staging-host" from tree to "test-staging-objects.cfg"
  - OR right-click host > "Move to..." > select "test-staging-objects.cfg"

Expected:
  - Orange arrow badge appears on the object (move indicator)
  - New file shows in target pane with staged indicator
  - Commit button badge count increased
  - Undo stack count increased
